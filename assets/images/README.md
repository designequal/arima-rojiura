# Image assets

公開前に、店舗から提供された素材または掲載許諾を確認した実写素材を配置してください。

想定ファイル:

- `hero.webp` — ヒーロー。推奨1600px以上
- `about.webp` — About用
- `gallery-01.webp` / `gallery-02.webp` / `gallery-03.webp` — Gallery用
- `ogp.webp` — OGP用
- `instagram-feed/*.webp` — Instagram同期で自動生成

実在する料理・店舗・人物をAI生成画像で代替しません。使用元と許諾はルートの `assets.md` に記録してください。
